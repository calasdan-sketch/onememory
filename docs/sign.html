Send a command

Signs it on this device. The secret is used here and never sent to the store.

Check a result

Results and the heartbeat are signed by the PC. Anyone with a store token can write a note that looks like a result; only a signed one is real.

If you only build it, paste the result into a new note in your commands namespace. The PC replies in results within one poll. Check the runner heartbeat note first if nothing comes back — a stale heartbeat means the PC is not listening, which is a different problem from a command being refused.
